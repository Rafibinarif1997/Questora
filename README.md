# HOOD MEMORY — COMPLETE FRONTEND FRAMEWORK

This is a complete static, multi-page product framework intended for GitHub Pages.

## Core rules implemented
- No single-page-only landing site.
- Each major section has its own URL.
- Buttons either navigate or execute a visible demo action.
- Public Demo NFT mode works locally with localStorage.
- Demo XP is stored locally.
- Mission submission form works as a local demo.
- Responsive/mobile UI.
- Animated visual identity.
- No React/Vite/build system required.
