# Arthood NFT — Frontend MVP

A static, responsive homepage prototype for the Arthood NFT marketplace / launchpad.

## Run locally
Just open `index.html` in a browser.

## Deploy to GitHub Pages
Upload `index.html`, `styles.css`, and `app.js` to a repository and enable GitHub Pages.

## Important
This is a frontend prototype. Wallet connection, NFT minting, marketplace contracts, Supabase, real blockchain data, and authentication are not connected yet.
